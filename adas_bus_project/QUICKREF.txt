## 🔧 Configure Zones

Edit `config/config.json`:

```json
"zones": {
    "left_blind_spot": {
        "points": [[0.02, 0.40], [0.28, 0.34], [0.34, 0.95], [0.02, 0.95]],
        "color": [0, 0, 255],
        "alert_message": "BLIND SPOT WARNING"
    }
}
```

- Points: 0.0-1.0 (relative to frame)
- Color: [B, G, R] format
- Any polygon shape supported
